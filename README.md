# Meridian Tennis — сайт

Статический сайт: `index.html` + `style.css` + `script.js`. Сборка не нужна,
внешних библиотек нет — можно просто загрузить папку на любой хостинг
(Netlify, Vercel, Cloudflare Pages, обычный хостинг с FTP).

## 1. Заявки в Telegram

Бот **@MeridianTennis_Bot** уже подключён, токен вписан в `script.js`.
Остался **один шаг** — указать, кому слать заявки.

### Осталось сделать (2 минуты)

1. Откройте **[t.me/MeridianTennis_Bot](https://t.me/MeridianTennis_Bot)**
   и нажмите **«Начать» / Start**.
   *Без этого Telegram вернёт «chat not found» — бот не имеет права
   написать человеку первым.*
2. Откройте **[@userinfobot](https://t.me/userinfobot)** — он пришлёт ваш `Id`
   (число вида `123456789`).
3. Впишите это число в `script.js`:

```js
chatId: '123456789'   // ← ваш Id из @userinfobot
```

Готово — заявки начнут приходить вам в Telegram.

> **Почему нельзя просто написать `@I700077`?**
> Telegram принимает `@username` в поле `chat_id` только для **публичных
> каналов**. Для личного аккаунта нужен числовой ID. Узнать его нужно
> один раз — он больше не меняется.

### ⚠️ Про безопасность токена

Токен сейчас лежит прямо в `script.js`. Этот файл браузер скачивает как
обычный текст, поэтому **токен виден любому посетителю сайта** — его можно
скопировать и рассылать сообщения от имени вашего бота.

Сделано так, чтобы форма заработала сразу. Когда будет время:

1. Разверните `telegram-proxy.js` (вариант A ниже) — токен уйдёт на сервер.
2. Перевыпустите токен: @BotFather → `/revoke` → выберите бота.
   Старый (тот, что сейчас в файле) перестанет работать.

### Вариант A — безопасный (рекомендуется в перспективе)

Токен остаётся на сервере, в браузер уходит только адрес воркера.

1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** →
   **Create** → **Worker** → **Deploy**
2. **Edit code** → вставить целиком содержимое `telegram-proxy.js` → **Deploy**
3. **Settings → Variables and Secrets** → добавить два **секрета**:
   - `BOT_TOKEN` — токен бота
   - `CHAT_ID` — ваш числовой ID
4. Там же добавить обычную переменную:
   - `ALLOWED_ORIGIN` — адрес сайта: `https://meridiantennis.github.io`
5. Скопировать адрес воркера и вписать в `script.js`:

```js
var CONFIG = {
    telegram: {
        proxyUrl: 'https://ваш-воркер.workers.dev',
        botToken: '',
        chatId: ''
    },
    getform: 'https://getform.io/f/broxxyva'
};
```

Бесплатного тарифа Cloudflare (100 000 запросов в сутки) хватит с большим
запасом.

### Вариант B — то, как настроено сейчас

```js
var CONFIG = {
    telegram: {
        proxyUrl: '',
        botToken: '8712844117:AAH...',   // уже вписан
        chatId: ''                        // ← осталось заполнить
    },
    getform: 'https://getform.io/f/broxxyva'

```

### Как это работает

Форма отправляет заявку **во все настроенные каналы сразу** и считает
отправку успешной, если сработал хотя бы один. Пока Telegram не настроен,
заявки продолжают приходить в Getform — форма не ломается ни на секунду.
Когда настроите Telegram, можно убрать `getform`, поставив `getform: ''`.

## 2.1. Хостинг: GitHub Pages

Адрес сайта — `https://meridiantennis.github.io/`. Он прописан в `index.html`
(`canonical`, Open Graph, schema.org), `robots.txt` и `sitemap.xml`.

### ⚠️ Репозиторий обязан называться `meridiantennis.github.io`

Все файлы лежат в корне репозитория, без папок — так задумано.
Но само **имя репозитория** решает, по какому адресу отдаётся сайт:

| Имя репозитория | Адрес сайта | Название и фавикон в Google |
|---|---|---|
| `meridiantennis.github.io` | `https://meridiantennis.github.io/` | «Meridian Tennis» + ваш логотип |
| любое другое (`1`, `site`, …) | `https://meridiantennis.github.io/1/` | «GitHub Pages documentation» + глобус |

Google берёт название сайта и фавикон **только с корня домена**. Для страницы
в подпапке он подставляет данные владельца домена — то есть самого GitHub,
и переопределить это мета-тегами со страницы невозможно.

Переименовать: репозиторий → **Settings** → **Repository name** → вписать
`meridiantennis.github.io` → **Rename**. Затем **Settings** → **Pages** →
убедиться, что Source = `Deploy from a branch`, ветка `main`, папка `/ (root)`.

После переименования старый адрес `/1/` отдаёт 404 — это нормально,
Google переиндексирует сайт за 1–3 недели. Ускорить:
[Search Console](https://search.google.com/search-console) → добавить ресурс
`https://meridiantennis.github.io/` → **Проверка URL** → **Запросить индексирование**,
и там же отправить `sitemap.xml`.

### Если появится свой домен

1. Создать в корне репозитория файл `CNAME` с одной строкой: `meridian-tennis.uz`
2. У регистратора: запись `A` на `185.199.108.153`, `185.199.109.153`,
   `185.199.110.153`, `185.199.111.153` (или `CNAME` на `meridiantennis.github.io`
   для поддомена `www`).
3. Заменить `meridiantennis.github.io` на новый домен в `index.html`,
   `robots.txt`, `sitemap.xml` и в `ALLOWED_ORIGIN` воркера.

Файл `.nojekyll` в корне отключает обработку Jekyll — без него GitHub Pages
игнорирует файлы, чьи имена начинаются с `_`.

## 3. Картинки

Все исходные PNG сохранены без изменений. Сайт показывает `.webp`
(основной вариант) и `.jpg` (fallback для старых браузеров, `<picture>`).

Фотографии галереи изначально маленькие (например, `Screenshot_1` —
682×528 px), а плитки галереи крупные, поэтому браузер их растягивал
и картинка «мылилась». Теперь `.webp` пересобраны в 2× разрешении
(Lanczos + лёгкая резкость) с качеством 92 — это заметно чётче, чем
апскейл силами браузера.

| | Было | Стало |
|---|---|---|
| Что реально грузит посетитель (webp + jpg) | ~0.43 МБ, мыльные | ~2.4 МБ, чёткие |

Если замените какую-то картинку, пересоздайте её `.webp` и `.jpg` —
иначе браузер продолжит показывать старую версию. Чем больше исходник
по пикселям, тем лучше: апскейлом настоящую детализацию не вернуть.

**Логотип и фавикон не трогали.**

## 4. Локализация

Три языка: RU / UZ / EN. Все тексты — в объекте `I18N` в `script.js`.
Чтобы поменять текст на сайте, правьте его **там**, а не в HTML: при
переключении языка скрипт перезаписывает содержимое элементов с атрибутом
`data-i18n`.

Выбранный язык и тема сохраняются в `localStorage`.

## 5. Проверки

- Форма: валидация имени/телефона/email/сообщения на трёх языках,
  маска телефона `+998 XX XXX XX XX`, honeypot против ботов,
  таймаут запроса 15 секунд.
- Доступность: skip-link, фокус-ловушки в меню и галерее, `aria-*`,
  управление с клавиатуры (Esc / ←  → в галерее), поддержка
  `prefers-reduced-motion`.
- Адаптив: от 280 px (Galaxy Fold) до 1440+; отдельно обработан
  альбомный режим телефона и «чёлка» iPhone (`env(safe-area-inset-*)`).
